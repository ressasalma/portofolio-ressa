# Ressa Portfolio

Website portofolio personal untuk menampilkan profil, keahlian, proyek, video editing, dan sertifikat Ressa Salma Fatikah.

## Tampilan

Portofolio ini memakai antarmuka interaktif dengan animasi halus, folder proyek yang dapat dibuka, galeri sertifikat bergerak, serta desain responsif untuk desktop, tablet, dan ponsel.

## Fitur

- Navigasi one-page dengan smooth scroll
- Menu navigasi responsif untuk perangkat mobile
- Bagian profil dan keahlian
- Galeri proyek dalam folder interaktif
- Kategori proyek Web Develop, Design, dan Video Editing
- Pratinjau gambar dan video dalam jendela ringkas
- Galeri sertifikat dengan animasi drift
- Favicon kustom
- Layout responsif untuk berbagai ukuran layar

## Teknologi

- React 18
- Vite 5
- CSS
- GSAP
- Motion
- OGL

## Menjalankan Proyek

### Prasyarat

Pastikan Node.js sudah terpasang.

### Instalasi

```bash
git clone <repository-url>
cd portofolio
npm install
```

### Mode Pengembangan

```bash
npm run dev
```

Buka alamat yang tampil pada terminal, biasanya `http://localhost:5173`.

### Build Produksi

```bash
npm run build
```

Hasil build tersedia pada folder `dist`.

### Preview Build

```bash
npm run preview
```

## Struktur Proyek

```text
portofolio/
├── images/
│   ├── certificate/          # File sertifikat
│   ├── design/               # Karya desain
│   ├── video/                # Karya video editing
│   └── web dev/              # Karya web development
├── src/
│   └── components/           # Komponen React
├── App.jsx
├── Portfolio.jsx             # Konten utama portofolio
├── Portfolio.css             # Gaya utama
├── index.html
└── package.json
```
